## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 使用独立计划 2026-10-14-legacy-router-migration | 不覆盖已有注释、电池通讯等任务计划 |
| 不触碰厂商 HAL、CMSIS、闭源库和 Keil 生成物 | 保留新框架电气换相边界及用户已有修改 |
| 用户明确要求不编译/烧录/静态检查 | 本次只做实现所需的代码阅读与编辑 |
| 保留旧活跃 VSP 20%~100% 线性 PWM＋新 64200 电气 RPM 上限 | 不把旧未调用六档 duty 表或未知机械转速当有效速度参数 |
| 不恢复旧六灯复用矩阵 | 原理图仅PA10照明，矩阵占用 EN/ADC 会破坏硬件接口 |

## Errors Encountered
| Error | Resolution |
|-------|------------|
| 无选择器且已有多个命名计划，解析器未返回目录 | 创建独立计划并显式选择，不恢复其他任务 |
| MOS 快检长片段未匹配，短片段重复 | 获取精确缩进后限定活跃函数，Edit 成功 |
| Python fitz 不可用 | 用已有 Poppler 放大到系统临时目录，未安装依赖 |
| main.c 目标行缩进不匹配 | 用唯一 ASCII 表达式替换成功 |
| MIN_TOOL_DUTY 行缩进不匹配 | 改为唯一宏值子串替换成功 |
| 探索协作者 Handback 工具受 auto-mode 限制 | 改用普通 SendMessage 交付，不改权限或模式 |
